## DREAM-HF (NCT02032004) — feasibility/information request

**Subject:** Data-access inquiry for independent, prespecified response-heterogeneity analysis of DREAM-HF

Dear DREAM-HF data-sharing contact / sponsor,

We are evaluating whether a rigorously governed, de-identified participant-level dataset could support a prespecified analysis of response heterogeneity and model transportability in chronic HFrEF. The proposed use is exploratory and would not treat DREAM-HF as validation of a different cell product or as evidence for an iPSC-derived patch.

ClinicalTrials.gov currently records DREAM-HF as a completed randomized sham-controlled phase 3 study (NCT02032004; 565 enrolled) and marks the IPD sharing plan “Yes.” Please confirm whether participant-level data are presently available, the permitted data scope, request mechanism, eligibility and review criteria, expected timeline/fees, data dictionary and coding conventions, and the required protocol, analysis plan, institutional review, and data-use agreement. If data can be requested, we would seek the de-identified data and supporting documents necessary for a prespecified analysis, subject to your approval and the original consent/data-use restrictions.

The analysis plan would be submitted for review before outcome inspection. It would identify outcomes and timepoints, missing-data handling, multiplicity, subgroup limitations, and an explicit no-transport/no-product-equivalence statement. We would not use these data to claim efficacy of a different product.

## REVIVED-BCIS2 (NCT01920048) — data-sharing route and reuse permission

**Subject:** Request for data-sharing policy and feasibility of a prespecified secondary model-validation analysis

Dear REVIVED-BCIS2 data custodian / corresponding investigator,

We are assessing whether de-identified participant-level data and required supporting documents from REVIVED-BCIS2 could be used for a prespecified secondary analysis of model calibration/transport in ischemic LV dysfunction. Aggregate REVIVED results already inform one component of our existing revival comparator analysis; therefore, we will not describe REVIVED as a held-out validation set for that component. Any distinct proposed analysis would declare all prior aggregate-data exposure and undergo an overlap/leakage review before access or outcome analysis.

Please direct us to the current data-sharing statement and request mechanism, including eligibility, review committee, data scope, protocol/SAP requirements, permissible outcomes and analyses, cost/timeline, data-use agreement, and restrictions on onward sharing or publication. Please also confirm whether baseline, longitudinal imaging, adjudicated events, treatment assignment, follow-up, and missingness fields are available in a sufficiently documented form for the proposed use.

We would submit a prespecified protocol and analysis plan, institutional privacy/ethics determination, and secure-data-management plan. No request for access is made by this template, and no validation claim will be made unless the overlap review passes and an independent analysis is approved.

Sincerely,
[Principal investigator / institution / institutional email / funding and conflict disclosures]

## BioVAT-HF / AATS-LB8 — feasibility and data dictionary inquiry

**Subject:** Request for study documentation and de-identified feasibility-cohort data access route

Dear study investigator / data custodian,

We are conducting a methods review of what can and cannot be learned from early-phase single-arm engineered-myocardium studies. If permissible, we would like to request the protocol, statistical analysis plan, outcome definitions, follow-up schedule, de-identified data dictionary, analysis populations, and the formal process for considering access to de-identified participant-level data.

The intended use, if approved, would be limited to descriptive feasibility, safety, delivery, follow-up, and exploratory response-characterization analyses. Because these cohorts are single-arm and small, we will not estimate a causal treatment effect, use them as randomized validation, or convert observed LVEF change into an individual treatment-response distribution without an appropriate design and validated assumptions.

Please advise on data availability, consent and ethics constraints, access criteria, fees/timeline, data-use terms, and the appropriate institutional route. We will provide an institutional protocol and secure-data plan if a formal request is invited.

Sincerely,
[Principal investigator / institution / institutional email / funding and conflict disclosures]
