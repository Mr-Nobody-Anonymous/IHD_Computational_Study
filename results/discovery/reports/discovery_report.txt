In-silico cure discovery: searching for a specification, not a cure
====================================================================
SIMULATION-ONLY DISCOVERY - outputs a candidate specification, never a cure. The randomised_proof criterion is excluded because no simulation can satisfy it. Nothing here is evidence, a therapy, or a recommendation.

WHY THIS CANNOT RETURN A CURE
The 'randomised_proof' criterion requires randomised human outcome evidence.
No simulation can generate it. This programme therefore searches the four
simulation-admissible criteria and returns a candidate specification. Calling
that a cure would be a definitional trick, not a discovery.

THE PROGRAMME
  0. Formalise the target [executable now]
     question: What exactly would count, and which criteria can a simulation address?
     exit gate: A written target with four admissible criteria and one explicitly excluded
  1. Feasibility frontier [executable now]
     question: Does any capability vector satisfy the admissible criteria?
     exit gate: Non-empty feasible region under conceivable bounds, empty under demonstrated
  2. Gap quantification [executable now]
     question: How far is each capability from the requirement?
     exit gate: Every gap expressed as a factor with a cited provenance
  3. Value of information [executable now]
     question: Which unknown, if measured, would most change the answer?
     exit gate: Capabilities ranked by decision variance resolved
  4. Minimal capability set [executable now]
     question: Which capabilities are indispensable versus already solved?
     exit gate: An irreducible set of required discoveries
  5. Adversarial falsification [requires new model structure]
     question: Does the candidate survive hostile but plausible assumptions?
     exit gate: Candidate retains a feasible region across structural perturbations
  6. Identifiability audit [requires new model structure]
     question: Are the governing parameters identifiable from obtainable data?
     exit gate: Every decision-relevant parameter has an identifiable measurement route
  7. Specification handoff [executable now]
     question: What is the cheapest real-world sequence that could convert this to evidence?
     exit gate: A specification a laboratory can act on, with the proof criterion still open

THE HONEST BOTTOM LINE
- Driver durability is already solved in principle by one-time editing.
- Substrate clearance is short by roughly a factor of two, and the modelled
  architecture's own ceiling only just clears the bar.
- Myocardial restoration is the binding discovery: nothing demonstrated is
  close, and no parameter tuning creates a capability that does not exist.
- Randomised proof stays open no matter how good the simulation gets.
- Therefore: a cure cannot be discovered in simulation. A specification can,
  and this is it.
